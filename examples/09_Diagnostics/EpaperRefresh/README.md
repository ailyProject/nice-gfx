# EpaperRefresh

针对 Waveshare 1.54 V2 黑白模组（SSD1681，200×200）的刷新诊断。先按实际接线填写全部六个引脚，特别是 RESET 和 BUSY。草图不会猜测引脚；保持 `-1` 时只输出配置提示。

首次建立全刷基线，随后的小区域读数变化使用匹配模组的局刷路径，按策略周期性全刷。初始化和物理 BUSY 由 `pollDisplay(millis())` 推进；没有 `delay()` 或等待刷新完成的循环。

Waveshare 2.9 V2 黑白模组可改用 `SSD1680_128x296_EPD_SPI`。其他型号不能仅凭相同控制器套用这两个模组的波形。更新周期、残影和温度范围需要目标实板验证。业务中持续处理按键，不要用 `displayRefreshing()` 阻塞菜单。
