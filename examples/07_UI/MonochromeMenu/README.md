# MonochromeMenu

SSD1306 128×64 I²C 的三项菜单，使用主库现有 `KeyInput` 去抖、重复及确认输入。反白选中项、文字及布局按单色屏设计，无动画和循环重绘。仅变动的像素字节会发送。

修改草图顶部的三个按键引脚，按键低电平按下；`-1` 表示未连接。按实际开发板初始化 `Wire` 的 SDA/SCL，默认 OLED 地址为 `0x3C`。SH1106 可替换显示类型为 `SH1106_128x64_I2C`，不改变菜单代码。字库与绘图需要足够 Flash/RAM，低端 AVR 应先检查编译占用。

这是基础绘图菜单示例；编辑器生成的原生 `View` 同样继续使用原有焦点、路由及实体按键接口。
